# رادار الشواغر السعودية

محرك يجمع الشواغر المعلنة في السعودية من منصات التوظيف وبوابات الشركات، ويطابق كل شاغر
مع سيرة عبدالسلام الفيفي الذاتية، وينشر النتيجة على لوحة تُحدَّث يوميًا.

---

## ماذا يجمع، وماذا لا يجمع — بصراحة

| الطبقة | المصادر | الحالة |
|---|---|---|
| **١ — واجهات برمجية منظّمة** | Workday, Oracle Recruiting, SuccessFactors, Greenhouse, Lever, SmartRecruiters, Ashby, Recruitee | جمع آلي موثوق. هذه هي بوابات التوظيف التي تستخدمها معظم الشركات الكبرى في السعودية. |
| **٢ — بوابات تعتمد جافاسكربت** | جدارات، صبار، طاقات، بيت.كوم، جلف تالنت، تنقيب، وظيفة | جمع آلي عبر متصفح بلا واجهة، يعترض طلبات JSON بدل الاعتماد على محددات CSS الهشّة. |
| **٣ — مقيّدة** | لِنكدإن، إنديد | **لا تُجمع آليًا.** كلاهما يمنع الكشط في شروط الاستخدام ويحجب عناوين مراكز البيانات. المحرك يولّد بدلًا من ذلك روابط بحث مضبوطة على تخصصك ومدنك وفترة النشر، وتظهر في لوحة منفصلة. |

الطبقة الثالثة لها مسار اختياري: `python run.py --local` يشغّل المتصفح على جهازك الشخصي
وبجلستك أنت. هذا يعمل تقنيًا، لكنه يبقى مخالفًا لشروط لِنكدإن — القرار قرارك، والافتراضي معطّل.

## كيف تُحتسب درجة المطابقة

خمسة معايير موزونة على ١٠٠، وكل رقم على اللوحة قابل للتتبع إلى النص الذي أنتجه:

| المعيار | الوزن | ما يقيسه |
|---|---:|---|
| المسمى الوظيفي | ٣٠ | قرب المسمى من المسميات المستهدفة في `config/profile.json` |
| تغطية المهارات | ٣٥ | حضور عناقيد مهاراتك (سلاسل إمداد، لين، جودة، تحليل بيانات، محاكاة) في نص الإعلان، بعوائد متناقصة |
| مستوى الخبرة | ١٥ | سنوات الخبرة المطلوبة، وإشارات «خريج/مبتدئ» مقابل «أقدم/مدير» |
| الموقع | ١٢ | أوزان المدن: الرياض وجازان ١٫٠، الشرقية ٠٫٩٥ … |
| حداثة الإعلان | ٨ | عمر الإعلان بالأيام |

**مرشّحات صارمة قبل التسجيل:** المهن خارج نطاق السيرة، والوظائف التي تتطلب ترخيصًا مهنيًا
أو مؤهلًا مختلفًا، تُستبعد بدرجة صفر بدل أن تُخفّض.

**الإعلانات بلا وصف:** إذا تعذّر جلب نص الإعلان، يُستبعد معيار المهارات وتُعاد موازنة
المعايير الأربعة الباقية على ١٠٠ — بدل احتساب المهارات صفرًا، وهو ما يظلم الشاغر. ثم يُطبَّق
سقف ٦٩ لأن الحكم بلا وصف حكم ناقص. اللوحة تعلن ذلك على كل بطاقة من هذا النوع.

## التشغيل لأول مرة

المحرك مصمَّم ليعمل على GitHub Actions: مجاني، وله إنترنت كامل، ويجدول نفسه يوميًا،
وينشر اللوحة على GitHub Pages برابط ثابت.

1. أنشئ مستودعًا جديدًا على حسابك باسم `ksa-job-radar` (خاص أو عام).
2. ارفع محتويات هذا المجلد إليه.
3. من **Settings → Pages** اختر المصدر: `GitHub Actions`.
4. من **Actions** شغّل `رادار الشواغر — تشغيل يومي` يدويًا أول مرة.
5. بعد انتهاء التشغيل ستجد رابط اللوحة في مخرجات خطوة `deploy`.

بعدها يعمل تلقائيًا كل يوم الساعة ٧:٣٠ صباحًا بتوقيت السعودية.

### التشغيل محليًا

```bash
pip install -r requirements.txt
python -m playwright install chromium

python scripts/discover_ats.py     # يحلّ بوابات الشركات مرة واحدة
python run.py --apis-only          # جمع سريع بلا متصفح
python run.py --all                # الجمع الكامل
python run.py --render-only        # إعادة بناء اللوحة من قاعدة البيانات
```

## البنية

```
config/profile.json      ملف المهارات المستخرج من السيرة — عدّله ليتغير التقييم كله
config/companies.yaml    سجل أصحاب العمل: محلولة + قائمة انتظار الاكتشاف
config/sources.yaml      المنصات الوطنية والمواقع التجميعية، وطبقاتها
radar/models.py          المخطط الموحّد، تطبيع النص العربي، توحيد أسماء المدن
radar/store.py           SQLite: منع التكرار، تتبّع أول ظهور، إغلاق المنتهية
radar/collectors/        جامعات الواجهات البرمجية + الجامع المعتمد على المتصفح
radar/matching/scorer.py محرك التقييم
radar/render/            قالب اللوحة ومولّدها
scripts/discover_ats.py  اكتشاف نظام التوظيف لكل شركة تلقائيًا
scripts/load_seed.py     تحميل الدفعة الأولية اليدوية
```

## تعديل ما يبحث عنه المحرك

كل شيء في `config/profile.json`: المسميات المستهدفة، عناقيد المهارات وأوزانها، أوزان المدن،
والمهن المستبعدة. لا حاجة لتعديل الكود لتغيير ما يبحث عنه المحرك أو كيف يقيّمه.

لإضافة صاحب عمل: أضِف سطرًا تحت `discover:` في `config/companies.yaml` برابط صفحة التوظيف،
وسيتولى `discover_ats.py` الباقي في التشغيل التالي.

## حدود معروفة

- بعض إعلانات جدارات تتطلب جلسة مسجّلة عبر أبشر؛ تُجمع بعناوينها ومواقعها فقط وتُقيَّم بالسقف المخفّض.
- `discover_ats.py` يتعرّف على البوابات المعروفة فقط؛ الشركة التي تدير موقع توظيف مخصصًا
  تبقى في قائمة الانتظار وتظهر في لوحة «حالة المصادر» بسبب الفشل.
- الدرجة أداة ترتيب لا حكم قبول. راجع الإعلان الأصلي قبل التقديم.
